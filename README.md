# 🇺🇸 Top 100 Companies in the United States — Web Scraping & Data Visualization

## 📌 Project Overview

This project focuses on **web scraping, data cleaning, analysis, and visualization** using data collected from Wikipedia.

I scraped information about the **Top 100 companies in the United States**, including their **company names, revenue, and number of employees**. The collected data was then cleaned and analyzed using Python and visualized to identify the largest companies based on revenue and workforce size.

The project demonstrates how web scraping can be combined with data analysis and visualization to turn raw web data into useful insights.

---

## 🎯 Objectives

* Scrape company data from Wikipedia.
* Extract relevant information such as:

  * Company name
  * Revenue
  * Number of employees
* Clean and transform the scraped data.
* Convert numerical columns into appropriate data types.
* Identify companies with the highest revenue.
* Compare companies based on the number of employees.
* Create visualizations to make the results easier to understand.

---

## 🛠️ Technologies Used

* **Python**
* **Requests** – Fetch web pages
* **BeautifulSoup** – Parse HTML and extract data
* **Pandas** – Data cleaning and analysis
* **Matplotlib** – Data visualization
